- (decision by coach) Pesquisa definida para comparar arquitetura Web hospedada localmente, OAuth e Google Calendar, modelagem de recorrencia e sincronizacao, seguranca e operacao local.
- (claim) ref=architecture-node status=verified class=architecture source=external-report|Node.js + SPA + SQLite e viavel, mas distribuicao exige validacao.
- (claim) ref=security-loopback status=verified class=security source=mdn-pna|Loopback, Origin, Host e CSRF devem ser tratados no servidor.
- (claim) ref=oauth-web-local status=verified class=version/compatibility source=google-oauth|Google documenta OAuth Web Server com localhost, state, escopos e acesso offline.
- (claim) ref=oauth-model status=verified class=version/compatibility source=google-oauth-rfc8252|Native Apps e Web Server local sao modelos que precisam ser distinguidos.
- (claim) ref=calendar-fields status=verified class=version/compatibility source=google-events|Events API suporta reminders, recorrencia, excecoes e IDs externos.
- (claim) ref=calendar-sync status=verified class=version/compatibility source=google-sync|Sync incremental exige full sync, nextSyncToken, paginacao e recuperacao de 410.
- (claim) ref=calendar-quota status=verified class=quantitative source=google-quota|Existem limites por minuto, 403/429 e exponential backoff.
- (claim) ref=pna-status status=verified class=security source=wicg-pna|PNA e draft e nao substitui defesas proprias.
- (claim) ref=node-child-process status=verified class=security source=node-child-process|Entrada nao sanitizada em shell pode executar comandos.
- (claim) ref=node-sea status=verified class=version/compatibility source=node-sea|Node SEA existe, mas esta em desenvolvimento ativo e possui restricoes.
- (claim) ref=domain-separation status=unverified class=architecture source=external-report|SQLite deve ser fonte de verdade do dominio e Calendar uma projecao externa.
- (claim) ref=recurrence-risk status=verified class=architecture source=google-events-sync|Recorrencia, excecoes e conflitos exigem prototipo antes de sync bidirecional.
