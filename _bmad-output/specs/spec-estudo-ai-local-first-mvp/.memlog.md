- (direction) Study AI is a browser-accessed local-first study continuity tool for a solo student; the MVP validates the next-session and session-lifecycle hypothesis before external integrations.
- (capability) CAP-1 Next-session agenda: the student can see the next local Session, its action, and same-day context; success: Home identifies the next Session or clearly states none is scheduled while retaining daily past and future Sessions.
- (capability) CAP-2 Session creation: the student can create an explicitly typed Managed Lesson or Free Block with planned time and duration; success: invalid records cannot be saved and valid records appear in the local agenda.
- (capability) CAP-3 Managed Lesson lifecycle: the system can start, time, complete, lose, and replace Managed Lessons under local rules; success: every valid transition is persisted with its outcome and original history remains auditable.
- (capability) CAP-4 Free Block timing and recurrence: the system can time local attention for Free Blocks and preserve recurrence plus occurrence exceptions; success: the block records local timing without claiming external-platform progress.
- (capability) CAP-5 Materials: the student can attach and open external links, PDFs, and local file references; success: safe material access failure never changes Session lifecycle state.
- (capability) CAP-6 Local history and recovery: the student can review lifecycle history and export or import local data; success: reloads preserve committed records and validated versioned JSON restores state atomically.
- (constraint) The Local Domain is the only source of truth for Session status, timing, recurrence, replacement, and history; all mutations go through application use cases and the architecture AD-1 through AD-12 remain binding.
- (constraint) The MVP is browser-first, local-hosted, single-user, single-active-tab, desktop/laptop oriented, and must work without network access or external authorization.
- (constraint) The implementation uses a lean hexagonal modular monolith with TypeScript, React, Vite, and IndexedDB behind a persistence port; timer truth comes from persisted timestamps and an injected Clock.
- (constraint) The global tolerance window is 50% of planned duration for both Managed Lessons and Free Blocks; after the boundary Start is blocked and the Session is Lost; planned end is never extended for late starts; Start and Stop are idempotent.
- (constraint) No MVP notifications, Google Calendar, OAuth, synchronization, local backend, multi-tab coordination, external-platform progress tracking, or generic planner behavior are allowed; Google Calendar is post-MVP only.
- (constraint) Local material persistence is hybrid: external links store validated http/https URLs and metadata; selected blobs up to 5 MB per file may be stored in IndexedDB; larger files require reselection. Backup uses versioned JSON and import replaces all local state only after complete validation.

- (decision) The later confirmed 50% tolerance and validity rule governs both Managed Lessons and Free Blocks; any earlier source wording that permits a different exception is superseded for the canonical MVP contract.
